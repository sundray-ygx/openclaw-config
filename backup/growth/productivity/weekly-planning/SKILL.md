# Weekly Planning Skill

自动从 OKR 拆解生成下周计划，并推送飞书确认。

## 功能

- 每周日 20:00 生成周计划草稿
- 筛选"产品经理"和"团队管理"领域的进行中项目
- 飞书推送候选项目供选择
- 确认后生成周计划和日计划
- 周一 08:30 自动生成下周每日计划

## 执行流程

```
周日 20:00
    ↓
读取 OKR 看板"我的项目"
筛选：领域=产品经理/团队管理，状态=进行中
    ↓
飞书推送候选项目列表
等待用户选择（回复数字）
    ↓
收到确认后
    ↓
生成周计划记录（PDCA看板）
关联选中的项目
生成周计划字段内容

周一 08:30
    ↓
读取选中的项目关联的任务
按下班时间分配任务到各日
    ↓
生成 5 天日计划记录
关联任务 + 生成今天安排
```

## 飞书交互

### 周计划草稿消息

```
📋 下周周计划草稿（3月17日-3月21日）

【候选项目】（产品经理/团队管理，进行中）
请回复数字选择要纳入的项目（多选用逗号分隔）：

1. ⭐ 集群1.0版本项目推进 [高优先级]
   └─ 截止日期: 2026-03-31
   
2. 📊 零中断2.0-ROF项目梳理 [高优先级]
   └─ 截止日期: 2026-03-25
   
3. 🔧 体系项目管理现状梳理 [中优先级]
   └─ 截止日期: 2026-04-15

【推荐选择】1,2（基于优先级和截止日期）

回复格式：
• "确认" → 按推荐选择
• "1,2,3" → 自定义选择  
• "跳过" → 本周不生成
```

### 确认后回复

```
✅ 周计划已生成

已选择项目: 集群1.0版本、零中断2.0-ROF
已创建周计划记录: https://notion.so/xxx

明天 08:30 将自动生成下周每日计划
```

```cron
# 周日 20:00 生成周计划草稿

30 8 * * 1
```
