# iOS 快捷指令导入说明

## 文件位置

- `同步睡眠数据.shortcut` - 快捷指令配置文件

## 导入步骤

### 方法一：直接导入（推荐）

1. 将 `.shortcut` 文件发送到 iPhone（AirDrop、邮件、iCloud Drive、微信文件传输等）
2. 在 iPhone 上点击该文件
3. 选择"添加快捷指令"
4. 完成导入

### 方法二：手动创建

如果直接导入失败，按以下步骤手动创建：

1. 打开"快捷指令"App
2. 点击右上角"+"新建
3. 按以下顺序添加操作：

## 修改 Worker URL

导入后需要修改为你的 Worker 地址：

1. 打开快捷指令
2. 点击"同步睡眠数据"
3. 点击第一个"文本"操作
4. 将 URL 改为你的实际地址（如 `https://your-name.workers.dev/api/health-data`）
5. 点击完成

## 设置自动化

1. 快捷指令 App → 底部"自动化"标签
2. 点击"创建个人自动化"
3. 选择触发条件：
   - **推荐**：特定时间 → 每天早上 8:00
   - 或者：关闭闹钟时
4. 添加操作：运行快捷指令 → 选择"同步睡眠数据"
5. **关闭** "运行前询问"
6. 完成

## 测试

首次运行建议手动测试：
1. 打开快捷指令 App
2. 点击"同步睡眠数据"
3. 查看是否显示"✅ 睡眠数据已同步"
4. 检查 Cloudflare Worker 日志
5. 检查 GitHub 仓库是否出现数据文件

## 故障排查

| 问题 | 解决 |
|------|------|
| 无法获取睡眠数据 | 确保 Apple Watch 已同步睡眠数据到健康App |
| 发送失败 | 检查 Worker URL 是否正确，网络是否正常 |
| 返回错误 | 检查 Cloudflare Worker 日志，确认 GitHub Token 有效 |
