# Security Audit Skill - Skill/MCP 安装前安全审计

## 审计触发条件

以下情况**必须**执行安全审计：
- `skillhub install <skill-name>`
- `clawhub install <skill-name>`
- 手动安装任何 Skill/MCP 扩展
- 更新现有 Skill/MCP 前

## 审计流程

### 步骤 1: 获取待安装内容

1. 列出 Skill 所有文件：
```bash
find ~/.openclaw/workspace/skills/<skill-name>/ -type f
```

2. 读取核心文件：
- `SKILL.md` - 使用说明和元数据
- `scripts/` 目录下所有脚本文件
- `references/` 目录下所有文档
- 任何可执行文件（.py, .sh, .js 等）

### 步骤 2: 内容分析

完整读取所有文件，分析以下方面：

#### 2.1 文件清单审计
- 检查文件类型分布
- 识别可执行脚本
- 标记未知/可疑文件扩展名

#### 2.2 代码行为分析
逐行分析脚本文件，重点关注：

**网络行为**
- 任何 HTTP/HTTPS 请求 (`requests`, `curl`, `wget`, `fetch`)
- WebSocket 连接
- DNS 查询
- 外部 API 调用

**文件系统操作**
- 读取/写入系统配置文件 (`/etc/`, `~/.openclaw/`)
- 修改核心文档 (`AGENTS.md`, `SOUL.md`, `MEMORY.md`)
- 访问敏感路径 (`/root/.ssh/`, `/etc/sing-box/`)
- 删除操作 (`rm`, `unlink`, `shutil.rmtree`)

**执行操作**
- 子进程调用 (`subprocess`, `os.system`, `exec`, `eval`)
- Shell 命令执行
- 动态代码执行

**权限操作**
- 权限修改 (`chmod`, `chown`)
- 提权尝试 (`sudo`, `setuid`)

**数据收集**
- 环境变量读取 (特别是 `*_API_KEY`, `*_TOKEN`, `PASSWORD`)
- 文件内容读取并外传
- 系统信息收集

### 步骤 3: 恶意行为检测

重点检查以下恶意特征：

| 风险类别 | 检测模式 | 风险等级 |
|----------|----------|----------|
| **数据外泄** | 发送敏感数据到外部服务器 | 🔴 高危 |
| **配置篡改** | 修改管理员ID、核心文档权限 | 🔴 高危 |
| **密钥窃取** | 读取密码/密钥并外传 | 🔴 高危 |
| **定时任务注入** | 添加未知定时任务 | 🔴 高危 |
| **后门逻辑** | 接受外部指令执行任意命令 | 🔴 高危 |
| **权限绕过** | 绕过权限检查的逻辑 | 🔴 高危 |
| **系统篡改** | 偷偷修改系统配置 | 🔴 高危 |
| **供应链攻击** | 下载并执行远程代码 | 🔴 高危 |
| **隐蔽通信** | 加密/混淆的网络通信 | 🟡 中危 |
| **过度权限** | 请求不必要的广泛权限 | 🟡 中危 |

### 步骤 4: 风险评估

根据检测结果计算风险评分：

```
风险评分 = Σ(风险项权重 × 置信度)

- 🔴 高危项: 权重 10
- 🟡 中危项: 权重 5
- 🟢 低危项: 权重 1
```

**决策阈值**:
- 评分 ≥ 10: **拒绝安装** - 存在高危风险
- 评分 5-9: **需人工审核** - 存在可疑行为
- 评分 < 5: **允许安装** - 风险可控

### 步骤 5: 结果处理

#### 发现高危风险时
1. **立即停止安装**
2. 记录风险详情：
   - 风险类型
   - 涉及文件
   - 具体代码片段
   - 风险说明
3. 推送告警给管理员
4. 隔离可疑文件（如有）

#### 发现中危风险时
1. **暂停安装**
2. 生成详细审计报告
3. 推送管理员确认
4. 等待人工决策

#### 确认安全时
1. 记录审计通过日志
2. 继续安装流程
3. 安装后持续监控

- `memory/security-audit-YYYY-MM-DD.md` - 每日审计日志
- `knowledge/lessons/skill-security-incidents.md` - 安全事件汇总

记录内容：

- 审计结果
- 发现的风险
- 采取的行动

## 告警通知

### 飞书告警配置

当检测到高危风险时，通过飞书插件发送通知：

**触发条件**:
- 风险评分 ≥ 10 (高危)
- 发现后门、密钥外泄、配置篡改等行为

**通知方式**:
使用 OpenClaw 飞书插件 (`openclaw-lark`) 的 `sessions_send` 功能

**手动发送告警**:
```bash
# 1. 生成告警消息
python3 ~/.openclaw/workspace/skills/security-audit/scripts/send_feishu_alert.py \
    "skill-name" 15 \
    --findings /tmp/security_findings.json \
    --output /tmp/alert_message.txt

# 2. 使用 sessions_send 发送到飞书（需指定目标会话）
# 在 OpenClaw 中执行:
# sessions_send(sessionKey="feishu:your_chat_id", message=alert_content)
```

**自动告警流程**:
1. 审计脚本检测到高危风险
2. 生成告警消息文件: `memory/security-alerts-pending.md`
3. 定时任务读取并发送到飞书
4. 或使用 `--alert` 参数直接触发

**告警内容示例**:
```
🚨 Skill 安全审计告警

━━━━━━━━━━━━━━━━━━━━━
📦 Skill: suspicious-skill
📊 风险等级: 🔴 高危
🔢 评分: 25/100
⚡ 建议操作: 立即拒绝安装
━━━━━━━━━━━━━━━━━━━━━

🔍 关键风险:
• 硬编码密钥
  文件: config.py 第15行
• 后门代码
  文件: main.py 第42行

⏰ 审计时间: 2026-03-20 14:46:00
```

**依赖**:
- 已安装 `openclaw-lark` 飞书插件
- 飞书插件已完成授权配置
