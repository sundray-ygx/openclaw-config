# 日报修复方案

## 问题清单

### 1. 飞书消息未覆盖
- 当前只扫描本地会话文件
- 飞书IM交互记录不在本地会话中

### 2. 反思任务超时
- 当前4:00执行，处理前天数据
- 需要调整到9:00，处理昨天数据（与日报同步）

## 修复方案

### 阶段一：日报增加飞书消息采集

修改 `/root/scripts/daily/daily_report.py`：

1. **增加飞书API调用模块**
   - 复用现有 `daily_report_main.py` 的 token 获取逻辑
   - 调用 `feishu_im_user_get_messages` 获取单聊消息

2. **时间范围对齐**
   - 使用与日报相同的时间范围（昨天00:00-23:59）
   - 转换为ISO 8601格式调用API

3. **消息解析与合并**
   - 解析飞书消息内容
   - 与会话文件数据合并统计
   - 在报告中增加"飞书交互"板块

### 阶段二：调整反思任务时间

1. 修改 cron 任务 `每日反思生成`
   - 从 4:30 调整到 9:30
   - 修改时间范围计算：处理"昨天"而非"前天"

2. 修复超时问题
   - 检查脚本执行时间
   - 必要时优化或拆分任务

## 实施步骤

1. 备份现有脚本
2. 修改 daily_report.py 增加飞书模块
3. 测试运行
4. 调整反思任务cron时间
5. 验证修复效果
