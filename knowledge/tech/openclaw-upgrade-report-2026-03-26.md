## 1. 最新版本更新内容 (v2026.3.23)

### 🔴 Breaking Changes（破坏性变更）
无

### 🟡 Changes（重要变更）

| 变更项 | 影响范围 | 详细说明 |
|--------|----------|----------|
| **ModelStudio/Qwen 端点更新** | 模型配置 | 新增标准 DashScope 端点支持（按量付费），支持中国和全球 Qwen API Key，提供商标签改为 `Qwen (Alibaba Cloud Model Studio)` |
| **UI 界面优化** | Web 控制面板 | 按钮组件统一、Knot 主题改为黑红配色、增加配置图标、圆角滑块改为离散档位、增强无障碍访问 |
| **CSP 安全策略** | Web 控制面板 | 为内联脚本计算 SHA-256 哈希并加入 CSP，提升安全性 |

### 🟢 Fixes（问题修复）

| 修复项 | 影响范围 | 详细说明 |
|--------|----------|----------|
| **插件运行时修复** | 插件系统 | 重新打包 WhatsApp、Matrix 等插件运行时文件，修复全局安装时缺失文件的问题 |
| **CLI 频道认证** | 命令行 | 单频道配置时自动选择登录频道，修复频道认证失败问题 |
| **OpenAI Token 认证** | 认证系统 | 修复 Token 保存后被内存旧值覆盖的问题，解决配置回滚到过期 Token 的 bug |
| **Control UI 权限** | Web 面板 | 修复操作员权限在设备认证绕过路径中丢失的问题 |
| **ClawHub 插件兼容** | 插件安装 | 安装时根据运行时版本检查 API 兼容性，修复版本检查失败问题 |
| **插件卸载** | 插件管理 | 支持卸载带版本号的 `clawhub:` 包名 |
| **Browser MCP 修复** | 浏览器自动化 | 修复 Chrome MCP 会话超时和重复授权问题（macOS） |
| **Browser CDP 修复** | 浏览器自动化 | 修复 Linux 无头环境下浏览器二次启动失败问题 |
| **Agent web_search** | 搜索功能 | 修复 Agent 使用错误搜索提供商的问题 |
| **Mistral 模型** | 模型配置 | 降低默认 max-token 值，修复旧配置问题 |

## 4. 升级建议

### 推荐操作

1. **升级 openclaw-lark 插件**（可选）
   ```bash
   openclaw plugins update openclaw-lark
   ```

2. **运行 doctor 检查**（推荐）
   ```bash
   openclaw doctor --fix
   ```
   这将自动修复 Mistral 等模型的配置问题

3. **重启 Gateway**（如需生效配置变更）
   ```bash
   openclaw gateway restart
   ```

### 无需操作

- Core 已通过 npm 自动更新到 2026.3.23-2
- 现有模型配置无需修改
- 飞书通道配置无需调整
