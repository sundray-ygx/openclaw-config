## 二、各安全机制详细说明

### 1. 🔴 红线指令拦截系统

**位置**: `AGENTS.md` 执行前自检

**解决问题**: 防止执行破坏性、危险性的系统命令

**防护范围**:

| 操作类型 | 示例命令 | 防护动作 |
|----------|----------|----------|
| 系统级删除 | `rm -rf /`, `rm -rf ~` | 直接拒绝 |
| 认证配置修改 | 修改 `openclaw.json` 认证 | 直接拒绝 |
| 密钥外发 | 发送私钥/API Key到外部 | 直接拒绝 |
| 管道安装 | `curl \| sh`, `wget \| bash` | 直接拒绝 |
| 反弹 Shell | `bash -i`, `nc -e` | 直接拒绝 |
| 提权操作 | `chmod 777 /etc` | 直接拒绝 |

**运行机制**:
- 执行任何 `exec` 或 `process` 前，扫描命令字符串
- 匹配危险模式 → 拒绝执行并报告原因
- 需人工确认后才能继续

### 2. 🟡 黄线指令审计系统

**位置**: `AGENTS.md` 执行后记录

**解决问题**: 记录敏感操作，便于事后审计

**记录范围**:

| 操作类型 | 示例 | 记录内容 |
|----------|------|----------|
| 特权操作 | `sudo` 命令 | 命令、时间、结果 |
| 扩展安装 | `skillhub install` | 来源、版本、审计报告 |
| 定时任务修改 | `cron add/update` | 变更内容、原/新配置 |
| 核心文件修改 | 修改 `AGENTS.md` 等 | 变更 diff、原因 |
| 网络外连 | `web_fetch` | 目标地址、内容摘要 |

**记录位置**: `memory/YYYY-MM-DD.md` 安全事件部分

---

### 3. 🔍 Skill/MCP 安全审计 (security-audit Skill)

**位置**: `~/.openclaw/workspace/skills/security-audit/`

**解决问题**: 防止恶意 Skill/MCP 扩展的安装

**审计流程**:
```
安装请求 → 获取文件清单 → 代码行为分析 → 恶意检测 → 风险评估 → 决策
```

**检测维度**:

| 风险类别 | 检测内容 | 风险等级 |
|----------|----------|----------|
| 数据外泄 | 发送敏感数据到外部 | 🔴 高危 (权重10) |
| 配置篡改 | 修改管理员ID、核心文档 | 🔴 高危 (权重10) |
| 密钥窃取 | 读取密码/密钥并外传 | 🔴 高危 (权重10) |
| 定时任务注入 | 添加未知定时任务 | 🔴 高危 (权重10) |
| 后门逻辑 | 接受外部指令执行命令 | 🔴 高危 (权重10) |
| 权限绕过 | 绕过权限检查 | 🔴 高危 (权重10) |
| 系统篡改 | 偷偷修改系统配置 | 🔴 高危 (权重10) |
| 供应链攻击 | 下载执行远程代码 | 🔴 高危 (权重10) |
| 隐蔽通信 | 加密/混淆网络通信 | 🟡 中危 (权重5) |
| 过度权限 | 请求不必要权限 | 🟡 中危 (权重5) |

**决策阈值**:
- 评分 ≥ 10: **拒绝安装**
- 评分 5-9: **需人工审核**
- 评分 < 5: **允许安装**

**日志记录**: `memory/security-audit-YYYY-MM-DD.md`

### 4. 🛡️ 核心配置防护 (config-guard Skill)

**位置**: `~/.openclaw/workspace/skills/config-guard/`

**解决问题**: 防止核心配置文件被篡改

**防护目标**:

| 文件 | 重要性 | 防护方式 |
|------|--------|----------|
| `~/.openclaw/openclaw.json` | 🔴 核心 | 权限600 + 哈希校验 + 自动恢复 |
| `~/.openclaw/devices/paired.json` | 🔴 核心 | 权限600 + 备份保护 |
| `~/.openclaw/devices/pending.json` | 🟡 重要 | 权限600 |

**防护机制**:

1. **权限加固**: 所有核心配置设为 `chmod 600`
2. **哈希基线**: 生成 SHA256 指纹，定期校验
3. **自动恢复**: 检测到篡改时从备份自动恢复
4. **双任务冗余**: 系统 crontab + OpenClaw 定时任务双重监控

**运行状态**: ✅ 正常运行
- 系统 crontab: `*/5 * * * * /root/.openclaw/scripts/check_config.sh`
- 每5分钟执行一次完整性校验

**监控指标**:
- CPU > 90% 的非白名单进程

**进程白名单**:
`openclaw`, `python3`, `node`, `sshd`, `cron`, `docker`, `systemd`, `bash`

**自动处理**: 发现异常进程 → 记录告警 → 自动终止
