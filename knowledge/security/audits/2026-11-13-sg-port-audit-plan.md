### 1.2 关键发现

1. **7500 是最高风险**：公网可达 + 弱口令 + 管理台可看全部隧道/踢隧道/改配置，无 2FA。
2. **5000/5005/3011 公网直连绕过 nginx 入口纪律**：DSM 5000 直暴 = 爆破 + CVE 面；3011 直连是明文 HTTP；5005 公网放行零收益（消费者全在本机）。
3. **自环探测存在假阴性**（23456/7023/7000 显示 000 但有活连接）：EIP 回流路径与外部真实路径不同。本报告用「监听+活动连接+自环」三角互证；**最终权威 = 阿里云控制台规则清单**，执行前以控制台为准核对。
4. fail2ban sshd 守备良好（已 ban 2757，现 ban 19），23456 保留有兜底。

### 补充证据（2026-11-13 11:05 追加）

1. **frps 7000 正被扫描爆破**：frps 日志 11:05:55 记录 123.58.204.138（hostname=dedsec-probe，windows）尝试 client login，token 不匹配被拒。实证 7000 公网可达 + 活跃攻击面 → B2 限源价值坐实。
2. **frpc 重连事件**：10:59:41-11:05:51 frpc 整体断开重连（全隧道重注册），期间 bill 域名 502 六分钟，已自愈。5005 WebDAV 隧道同窗口受影响后恢复。
3. 探测指纹模型修正：瞬时 000（<0.03s）= 端口 SG 放行（非 HTTP 服务或 RST）；4s 超时 = SG DROP；有效 HTTP 码 = 放行且 HTTP 服务。据此 3100/3200/3300/3012 四口为「疑似放行」——控制台核对时一并确认。

五项全部零业务影响、可秒级回滚（控制台重新加规则）。
