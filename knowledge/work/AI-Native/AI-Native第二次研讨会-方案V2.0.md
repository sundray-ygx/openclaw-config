# 三、各产线分享交流（核心环节，110min）

### 时间分配

7条产线（含综管部），每条产线 **15分钟**：
- **8分钟** 产线分享
- **7分钟** 互动讨论

### 产线分享框架（每条产线8分钟）

#### 第一部分：最新进展及效果（5分钟）

1. **AI-Native落地最新进展**
   - 关键里程碑完成情况（对照OKR/里程碑计划）
   - 已落地的AI场景及覆盖范围
   - 量化数据（覆盖率、提效比例、使用频次等，有则报）

2. **能否支撑年度目标达成？**
   - ✅ **能达成**：说明哪些场景已验证有效，按当前节奏可以完成年度目标
   - 🟡 **有风险**：说明哪些环节有瓶颈，什么条件下能达成
   - 🔴 **大概率不能达成**：说明核心障碍是什么，为什么现有方案走不通

3. **效果展示**（如有）
   - 1-2个典型场景的实际效果案例
   - 可以用截图、数据、案例说明

#### 第二部分：接下来的落地计划（3分钟）

1. **下阶段落地计划**
   - 近期（2-4周）关键行动
   - 是否能支撑年度目标达成

2. **自我评估归类**
   - 🟢 **能达成** — 可以分享经验
   - 🟡 **有风险** — 希望听取其他部门建议
   - 🔴 **有困难** — 需要提取为公共问题

### 互动讨论（7分钟）

根据产线自我评估，进入不同讨论模式：

**🟢 能达成的产线** → 经验分享模式
- 其他产线提问："这个经验在我们产线能不能复用？"
- 讨论可行性、适配成本
- 主持人引导："谁觉得这个做法可以借鉴？"

**🟡 有风险的产线** → 集体诊断模式
- 其他产线提供建议："我们遇到类似问题是这样解决的……"
- 讨论是否存在可行方案
- 主持人引导："有没有人有相关经验？"

**🔴 有困难的产线** → 提取公共问题模式
- 主持人判断：这是个别问题还是共性问题？
- 如果是共性问题 → 标记为"公共问题"，纳入后续专题
- 主持人引导："还有谁也遇到这个问题？"

# 四、跨产线经验提炼（20min）

### 经验提炼

讨论结束后，主持人快速归纳：

1. **可复用经验 TOP3**
   - 哪些经验被多个产线认可可借鉴？
   - 谁来牵头整理成可复用的最佳实践？

2. **公共问题清单**
   - 所有产线都无法解决、需要研发体系层面攻克的问题
   - 按优先级排列
   - 提议作为后续AI布道师会议专题

3. **风险产线的应对建议**
   - 针对有风险的产线，汇总各方建议
   - 明确下一步行动
