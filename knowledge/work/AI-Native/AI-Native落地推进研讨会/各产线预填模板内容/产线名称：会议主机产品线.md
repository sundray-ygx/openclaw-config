# 一、当前落地障碍

## 障碍①：人力不足，TL 赋能难以集中推进

- **描述**  
  当前团队人力不足，成员已有较重的工作任务。AI-Native 自动化需先从技术负责人（TL）层面推广，再逐步扩展至全员，过程中需要响应与调试。但当前负责人身兼多职、任务繁重，难以抽出专门时间针对性推进。

- **影响**  
  TL 赋能无法集中推进 → 全员推广整体延后，Q2 覆盖率目标存在风险。

- **已尝试的解法**  
  利用个人零散时间进行推进。

- **需要的支持**  
  请求适当分担现有工作职责，使其能够集中精力先对 TL 进行赋能，并推动后续全员推广工作。

- **影响**  
  实时同步功能缺失 → AI-Native 无法从试点走向全员使用，推广卡在最后一环。

- **已尝试的解法**

- **需要的支持**  
  需提供相应的时间资源，以完成该功能的开发与上线。
