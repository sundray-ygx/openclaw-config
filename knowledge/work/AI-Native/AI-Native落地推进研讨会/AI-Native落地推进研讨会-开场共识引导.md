## 第2页：方法论框架

```
战略层（已完成）              执行层（今天引入）
┌───────────┐              ┌───────────┐
│ RPP + PPT │   ──拆解──→  │ PGSAR闭环  │
│ 为什么做    │   执行       │ Plan       │
│ 怎么组织    │              │ Goal       │
│            │              │ Standard   │
│            │              │ Action     │
│            │              │ Review     │
└───────────┘              └─────┬─────┘
                                 │
                           ┌─────↓─────┐
                           │ SMART原则  │
                           │ 目标质量    │
                           └───────────┘
```

**简单理解**：
- RPP+PPT → **为什么做、怎么组织**（已有，不重复讨论）
- PGSAR → **具体做什么、怎么衡量、怎么纠偏**（今天核心）
- SMART → **目标质量检查**（确保经得起推敲）

## 第3页：PGSAR闭环

```
 P(Plan)     检视整体计划，确认方向
    ↓
 G(Goal)     SMART拆解，大目标→小目标
    ↓
 S(Standard) 定义"做好了"的标准，可衡量
    ↓
 A(Action)   明确行动、责任人、时间
    ↓
 R(Review)   定期检视，红黄绿灯，偏差纠偏
    ↓
    └──→ 回到Plan，调整优化，持续循环
```

**一句话**：计划 → 拆解 → 定标准 → 行动 → 检视 → 调整，循环往复。

## 第4页：SMART原则 — 目标质量检查

| 维度 | 问什么 | ✅ 合格 | ❌ 不合格 |
|------|--------|---------|----------|
| **S**pecific | 做什么？交付什么？ | 有明确交付物 | "推进AI应用" |
| **M**easurable | 怎么衡量？ | 有量化指标 | "提升效率" |
| **A**chievable | 能做到吗？ | 信心≥7 | 目标远大无路径 |
| **R**elevant | 和OKR什么关系？ | 能追溯到KR | 孤立任务 |
| **T**ime-bound | 什么时候完成？ | 有明确截止日 | "尽快""年底前" |

**核心工具：信心指数** __/10
- **≥8** → 直接拆解行动
- **5-7** → 有风险，讨论卡在哪，可能要拆分
- **<5** → 重新定义或大幅拆分
