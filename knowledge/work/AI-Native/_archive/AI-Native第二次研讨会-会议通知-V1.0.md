# AI-Native 落地情况持续跟踪研讨会 — 会议通知

**各位产线负责人/AI布道师：**

继4/27第一次研讨会后，本周一（5月11日）晚将召开第二次研讨会，主题调整为**落地情况持续跟踪 + 产线分享交流**。

## 会议信息

- **时间**：5月11日（周一）19:00 - 21:30（2.5小时）
- **参会人**：各产线AI布道师/项目主管 + 产线负责人（或指定代表）
- **覆盖产线**：无线、交换机、NMC、会议主机、IPSIP、硬件、综合管理部

## 本次会议目标

1. **摸清现状**：各产线AI-Native最新落地进展及效果，能否支撑年度目标达成
2. **经验共享**：进展好的产线分享经验，其他产线评估可复用性
3. **风险应对**：有风险的产线听取其他部门建议，寻找可行方案
4. **提取公共问题**：各产线都无法解决的问题，提取为研发体系公共课题

## 议程

| 时间 | 环节 |
|------|------|
| 19:00-19:10 | 开场说明 |
| 19:10-21:00 | **各产线逐一分享交流**（每条产线15分钟：8min分享 + 7min讨论） |
| 21:00-21:20 | 跨产线经验提炼 + 公共问题提取 |
| 21:20-21:30 | 总结与后续安排 |

## 各产线分享内容（8分钟）

每条产线请按以下结构准备：

**1. 最新进展及效果（5分钟）**
- 关键里程碑完成情况
- 已落地AI场景及量化效果
- **能否支撑年度目标达成？逐条说明**（重点！）
  - ✅ 能达成 → 说明哪些已验证
  - 🟡 有风险 → 说明瓶颈
  - 🔴 有困难 → 说明核心障碍

**2. 接下来的落地计划（3分钟）**
- 近期关键行动（2-4周）
- 计划能否支撑年度目标
- 自我评估归类：🟢能达成 / 🟡有风险 / 🔴有困难

**讨论环节（7分钟）根据状态进入不同模式：**
- 🟢 能达成 → 分享经验，其他产线评估可复用性
- 🟡 有风险 → 集体诊断，其他产线提供建议
- 🔴 有困难 → 提取为公共课题，后续AI布道师会议专题攻克
