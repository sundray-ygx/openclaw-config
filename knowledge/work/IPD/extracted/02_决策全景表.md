## 参与类型说明

| 参与类型 | 说明 |
|----------|------|
| **发起（主导）** | 主导活动开展，对结果负责，包含评审前内容准备、发起会议评审、保障会议纪要闭环 |
| **评审表决** | 代表自身领域做商业决策/技术评审，把关风险，提出问题和建议，投票表决 |
| **建议参评** | 作为关联领域专家或关键下游角色，建议参与评审，补充专业意见，不参与表决 |
| **按需参与** | 基于前期研讨未达成一致的，由PDT代表按需邀请参与，不表决 |
| **综合管理部** | 负责流程赋能、电子流预审、评审决策过程规范引导、会后基线会议结论 |
| **共同开发&评审表决** | 参与共同开发并参与评审表决 |

## 决策原则

1. 各PDT代表代表领域和体系整体意见，会前需先做好体系内沟通和共识
2. 提前48小时发起电子流评审，各评审表决人至少提1个问题
3. 各评审表决人充分发表意见，一人一票严肃表决
4. **全票通过制**
5. 争议点决策：DCP/MR/SR/TR1争议由PDT经理决策，TR2-TR7争议上升到研发体系主管决策
