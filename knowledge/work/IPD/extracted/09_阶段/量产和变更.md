# 量产和变更


> **版本**：V2.0（基于5月7日更新版本）
> **阶段类型**：全生命周期  
> **阶段定位**：确保量产质量和变更可控

---

## 一、阶段概览

### 1.1 活动目的/意图

- 确保量产阶段的产品**质量稳定**
- 确保变更**可控**，避免变更引入质量风险
- 确保供应链稳定，避免缺货或库存问题

### 1.2 子阶段划分

| 子阶段 | 名称 | 核心目的 |
|--------|------|----------|
| 需求计划 | 需求预测和计划 | 确保量产数量合理 |
| 变更计划 | 变更计划管理 | 确保变更有计划、可控 |
| 变更验证和审核 | 变更验证审核 | 确保变更质量 |
| 变更到仓库检验入库 | 入库检验 | 确保入库质量 |
| 飞行检查（审厂） | 审厂检查 | 确保生产质量 |
| 批量入库后抽检或全检 | 批量检验 | 确保出货质量 |

### 1.3 变更来源

- 供应商发起PCN（Product Change Notice）
- 内部发起ECN（Engineering Change Notice）

## 四、质量运营

### 4.1 质量风险

| 子阶段 | 质量风险 |
|--------|----------|
| 需求计划 | 计划若偏多，可能导致库存问题或因长时间存放产生质量风险；计划若偏少，可能导致部分缺货影响渠道和客户满意度 |
| 变更计划 | 若未识别的变更，则会导致质量不可控；能不变是最好的，变本身就容易引入风险 |
| 变更验证和审核 | 验证用例缺失导致漏测 |
| 入库检验 | 检测粒度和时间比正式测试少，有引入质量风险可能 |
| 飞行检查（审厂） | 部分依赖经验，经验差或检查时间可能引入质量不可控 |
| 批量入库后抽检/全检 | 检测粒度和时间少，有质量风险；年底最后几天批量入库可能因发货压力导致检验不足 |

### 4.2 预防措施

- 严格变更管理流程
- 完善检验标准和检验时间保障
- 减少对个人经验的依赖
