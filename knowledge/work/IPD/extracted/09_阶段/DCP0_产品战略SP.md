## 一、阶段概览

### 1.1 活动目的/意图

- 确定质量的**战略目标**和**关键矛盾**
- 选定战场和关键价值，避免在错误的战场和价值里去改进质量和体验
- 确保战略方向对客户价值有实际帮助
- 完成产品线**业务设计**：回答"在哪里竞争"和"如何赢"

### 1.2 阶段定位

DCP0 是整个 IPD 流程的**第一个决策点**，对应 SPBP 中的"**市场洞察及战场选择**"+"**业务设计-如何赢**"两部分。由业务ST团队负责评审，产线主导完成。

DCP0 的核心是回答三个战略问题：
1. **在哪里竞争**（市场洞察 → 战场选择）
2. **如何赢**（业务设计：战略意图 + 目标客户 + 价值主张 + 竞争策略）
3. **如何保障**（质量投入 + 三代规划 + 组织保障）

### 1.3 时效性要求

- 无特定时效性要求（战略级节点，通常按年度规划周期）

## 二、SPBP 文档结构（DCP0 部分）

> 来源：XXX产品线-SPBP战略规划(XX年度)-V3.8-2025版.docx

### 2.1 第一部分：市场洞察及战场选择

#### 2.1.1 市场趋势洞察关键结论

| 洞察维度 | 关键内容 |
|----------|----------|
| **投资分布趋势** | 预判客户未来3-5年的投资分布和技术趋势（如基础大模型客户会使用什么技术栈） |
| **技术趋势分析** | 不同层级模型的投资分布、关键技术变化 |
| **差距分析（看自己）** | 客户差距（未被满足的需求）、业绩差距（当前经营vs期望）、机会差距（现有vs新业务设计） |
| **竞争对手情况（看友商）** | 主要竞争对手的产品、市场策略、赢得竞争的思路 |

**差距分析方法**：
- **客户差距**：未被满足的需求是创新的源泉；客户差距和机会差距往往需要新的业务设计
- **业绩差距**：现有经营结果和期望值之间的量化差距（当下差距），可通过高效执行填补
- **机会差距**：现有经营结果和新业务设计所能带来的经营结果之间的差距（未来差距）

#### 2.1.2 未被满足的客户及场景

**分析方法**：
1. 识别用户哪些未被满足好的需求（不仅是我们不能满足，其他厂商也不能满足）
2. 分析哪些适合我们做？哪些我们不该做？并讲清楚原因
3. 评估市场容量、技术架构、适配性

**注意事项**：
- 传统产品（AF/AC/VPN/HCI/AD/aDesk）聚焦两件事：产品品质（含环境适配性）+ 线上订阅融合
- 战场选择时要先分析客户未被满足的需求/场景（找到痛点和强刚需），再到战场选择

#### 2.1.3 机会及战场选择结论

**战场/机会点分析原则**：
1. 以**长期视角**看待机会选择，而非短期机会主义
2. **市场容量**：看未来不看现在，以动态眼光预判
3. **市场发展趋势**：解决方案生命周期，问题会越来越严重还是越来越少
4. **竞争和现状**：有无先发优势，选择早期市场或技术转型期
5. **能力匹配**：正推法、倒推法，重要新业务 All in

**输出结论**：
- 产品刷新后的**战场全景图**
- 每个战场的策略汇总
- 产品战场选择与行业战场选择**互锁结论**

### 2.2 第二部分：业务设计-如何赢

#### 2.2.1 战略意图

| 维度 | 内容 |
|------|------|
| **愿景** | 可持续的、占优势的业务领先地位，展示长期获利能力 |
| **中期目标（1-3年）** | 财务目标、产品/服务目标、市场目标（区域/客户）、技术目标、重要里程碑 |
| **短期目标（1年）** | 利润、成长率、市场份额、客户满意度、新产品 |

**战略意图结构**：
- 按海外/覆盖/KA三大市场分解，一套研发匹配三大市场体系
- 第一优先级：国内覆盖市场
- 第二优先级：国际市场
- 第三优先级：国内KA市场

#### 2.2.2 目标战场业务设计

每个战场需要回答**战略三要素**：

| 要素 | 关键问题 |
|------|----------|
| **目标客户是谁** | 明确客户画像和细分市场 |
| **价值主张是什么** | 在什么场景、给客户提供什么价值？如何用独特方式实现？ |
| **竞争策略是什么** | 对已有竞争对手怎么赢？通过独特价值、特有技术、不同客户细分、更低成本还是独特渠道？ |

成熟产品需重点考虑如何通过**订阅**来提升竞争力。

#### 2.2.3 产品质量投入分析

**质量需求来源**：
1. **产品战略分解**的质量诉求（如某行业某场景突破需识别客户视角的质量障碍）
2. **质量属性基线差距**（各质量属性底线要求vs当前满足情况的差距）
3. **存量客户满意度问题**（VOC、QMS、客户满意度、CTI网上问题、技术债等）

**质量分析维度**：
- 面向国内市场（含不支持场景定义）
- 面向海外市场（独特需求单列，避免被忽视）

#### 2.2.4 产品"三代规划"落地

**三代规划定义**：
- 产品战略洞察、需求开发、研发投入进行滚动开发
- 任何时候都有3代版本

**规划内容**：
- 一、产品演进的整体思路
- 二、产品架构演进思路
- 三、产品技术演进思路

## 五、质量运营

> 来源：06_质量运营全景表.md

### 5.1 质量风险

| 风险 | 说明 |
|------|------|
| 战略目标选定不清 | 质量的战略目标和关键矛盾选定不清 |
| 战场选择错误 | 在错误的战场和价值里去改进质量和体验，对客户价值无帮助 |

### 5.2 预防措施

- 在战略阶段就明确质量的战略目标和关键矛盾
- 确保战场选择和关键价值定义清晰
- 质量投入分析需与服务代表、质量主管/VOC代表对齐
- 质量目标不能只是改BUG，要服务于战略及目标客户

## 六、流程活动

### 6.1 主要活动步骤

1. **市场洞察**：分析行业/客户/市场投资趋势、技术趋势、差距、竞争对手
2. **未被满足需求识别**：找到客户痛点和强刚需
3. **战场选择**：分析机会点，确定战场选择结论
4. **市场互锁**：与行业事业部对齐战场选择
5. **战略意图制定**：明确愿景、中期目标、短期目标
6. **业务设计**：各战场完成目标客户、价值主张、竞争策略设计
7. **质量投入分析**：国内外市场质量目标和改进措施
8. **三代规划**：产品/架构/技术演进规划
9. **组织DCP0评审**：业务ST团队评审表决
10. 评审通过后进入DCP1

### 6.2 关键检查点

- [ ] 市场洞察是否充分（投资趋势、技术趋势、差距、竞争对手）
- [ ] 战场选择是否有充分论据支撑
- [ ] 战场选择是否与市场互锁
- [ ] 各战场业务设计是否完成战略三要素
- [ ] 质量投入分析是否与服务代表/VOC对齐
- [ ] 三代规划是否完整（产品+架构+技术）
