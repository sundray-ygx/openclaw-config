# DCP2-1 - 立项决策（规划基调）


> **版本**：V2.0（基于5月7日更新版本）
> **阶段类型**：DCP决策评审  
> **阶段定位**：明确立项方向，确定客户/市场选择和价值主张  
> **前置阶段**：DCP1  
> **组织模式**：以CDT团队进行活动

---

## 一、阶段概览

### 1.1 活动目的/意图

- 明确该规划的**客户/市场选择**
- 明确该规划的**商业价值**
- 明确该规划的**价值主张**
- 初步确认**技术/成本可行性**

### 1.2 阶段定位

DCP2-1是立项决策的第一步，聚焦"规划基调"。以CDT（Charter Development Team）团队进行活动，由PDT规划代表主导发起。

### 1.3 时效性要求

- 根据BP路标定义

## 二、准入准出

> 来源：04_准入准出全景表.md

### 2.1 准入条件

| 角色 | 准入条件 |
|------|----------|
| PDT规划代表 | 产线OKR导出的规划项 OR 市场OR导入（标准？） |
| PDT软件研发代表 | 产线OKR导出的规划项 OR OR导入（客服） |
| PDT硬件研发代表 | 基于ECN/PCN变更发起的规划 |

### 2.2 准出标准

| 角色 | 准出标准 |
|------|----------|
| PDT规划代表 | 市场洞察过程信息 + 市场洞察结论 + 规划基调（对应《项目规划表》的商业分析部分或charter的立项报告）+ 规划基调评审结果（邮件） |

| PDT供应链代表 | PCN/ECN原始需求基本信息变更决策评审结果 + 规划基调评审结果（邮件） |
| 产品线ST代表 | CDT任命通知（邮件） |
| PDT国内市场代表 | - |
| PDT国际市场代表 | - |

### 2.3 关键交付物

- 规划基调文档
- 规划基调评审结果（邮件）
- CDT任命通知

## 五、流程活动

### 5.1 主要活动步骤

1. 产线OKR导出规划项，发起CDT团队
2. 各领域提供输入（市场洞察、技术预研、硬件规划、供应链分析）
3. PDT规划代表主导完成规划基调
4. 组织规划基调评审
5. 评审通过后发布规划基调评审结果邮件
6. 进入DCP2-2 charter开发

### 5.2 关键检查点

- [ ] 规划基调的市场洞察是否充分
- [ ] 技术可行性是否初步确认
- [ ] 客户/市场选择是否明确
- [ ] CDT团队是否任命
