## 文档使用指南

### 1. 项目启动阶段

1. 查看 [项目类型.md](01_项目计划/项目类型.md)，确定项目类型
2. 使用 [charter计划表.md](01_项目计划/charter计划表.md) 制定charter
3. 参考 [基本风险库.md](02_风险管理/03_基本风险库.md) 识别项目风险
4. 使用 [风险管理表.md](02_风险管理/01_风险管理表.md) 建立风险清单

### 2. 项目规划阶段

1. 使用 [里程碑计划.md](01_项目计划/里程碑计划.md) 制定关键里程碑
2. 完善 [风险管理表.md](02_风险管理/01_风险管理表.md)，更新风险评估
3. 查看 [在途项目信息.md](03_项目汇总/在途项目信息.md)，了解相关项目

### 3. 项目执行阶段

1. 使用 [过程记录.md](01_项目计划/过程记录.md) 记录项目进展
2. 使用 [项目问题跟踪表.md](02_风险管理/02_项目问题跟踪表.md) 跟踪和解决问题
3. 定期更新 [风险管理表.md](02_风险管理/01_风险管理表.md)，跟踪风险状态

### 4. 项目收尾阶段

1. 更新 [过程记录.md](01_项目计划/过程记录.md)，记录项目总结
2. 更新 [在途项目信息.md](03_项目汇总/在途项目信息.md) 或 [26年发布项目信息.md](03_项目汇总/26年发布项目信息.md)
3. 归档 [风险管理表.md](02_风险管理/01_风险管理表.md) 和 [项目问题跟踪表.md](02_风险管理/02_项目问题跟踪表.md)
