# 新员工AI-Coding培训方案（通用版）

> **适用对象**：校招新人（0-2年经验）
> **培训周期**：3个月（含1个月课题实践）
> **核心目标**：掌握AI辅助编程工具，完成一个完整研发课题
> **课题特点**：通用技术方向，不绑定具体产品业务

---

## 一、培训体系概览

### 1.1 培训阶段

| 阶段 | 时长 | 内容 | 产出 |
|-----|------|------|------|
| 第1阶段 | 2周 | AI工具基础 + 代码规范 | 工具熟练度考核 |
| 第2阶段 | 2周 | 技术栈熟悉 + 小任务热身 | 热身任务Demo |
| 第3阶段 | 4周 | 课题实践（导师制） | 课题成果演示 |
| 第4阶段 | 2周 | 成果整理 + 复盘 | 技术分享会 |

### 1.2 AI工具清单

| 类别 | 工具 | 用途 |
|-----|------|------|
| 代码生成 | GitHub Copilot / Cursor | 日常编码辅助 |
| 代码审查 | CodeRabbit / Copilot Chat | 代码Review |
| 架构设计 | Claude / ChatGPT | 方案设计讨论 |
| 文档生成 | AI注释 / README生成 | 技术文档撰写 |
| 调试辅助 | AI异常分析 | Bug定位辅助 |

### 1.3 AI-Coding核心能力培养

```
┌─────────────────────────────────────────┐
│           AI-Coding 能力模型             │
├─────────────────────────────────────────┤
│  1. 提示工程能力 → 精准描述需求          │
│  2. 代码审查能力 → 判断AI输出质量        │
│  3. 迭代调优能力 → 持续优化结果          │
│  4. 架构设计能力 → 把控整体方案          │
│  5. 工程实践能力 → 落地完整项目          │
└─────────────────────────────────────────┘
```

## 三、硬件研发工程师课题（3个）

### HW-01: 嵌入式系统温度监控与告警平台 ⭐⭐⭐

**课题目标**
基于通用嵌入式开发板（如树莓派/ESP32），搭建温度监控系统，掌握嵌入式开发全流程。

**技术要点**
1. **硬件接口**
   - DS18B20温度传感器驱动
   - GPIO/I2C接口编程
   - ADC采集（如使用热敏电阻）

2. **嵌入式开发**
   - 裸机编程或FreeRTOS
   - 中断与定时器使用
   - 低功耗设计基础

3. **数据上报**
   - MQTT协议接入
   - JSON数据格式
   - 网络连接管理

4. **告警功能**
   - 阈值配置与判断
   - 本地LED/蜂鸣器告警
   - 远程通知（Webhook/邮件）

**AI辅助点**
- 传感器驱动代码生成
- MQTT客户端代码框架
- 阈值算法实现
- 调试日志分析

**交付物**
- 可运行的嵌入式程序
- 硬件接线图
- 使用说明文档

**校招适配**：✅ 推荐，硬件基础通用

### 8.2 AI工具使用规范

**✅ 推荐做法**
- 用AI生成代码框架和模板
- 用AI解释复杂代码逻辑
- 用AI生成单元测试用例
- 用AI辅助代码审查
- 用AI生成技术文档草稿

**❌ 禁止做法**

- 用AI生成代码不添加注释

- 不测试直接相信AI输出
- 用AI生成代码不理解原理
