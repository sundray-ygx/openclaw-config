## 一级目录

| 目录 | 用途 |
|------|------|
| `work/` | 公司职场（AI-Native、IPD、OKR、BP） |

| `reflection/` | 反思与方法论（每日反思、改进指南） |
| `security/` | 安全审计（跨领域） |
| `people/` | 人物信息 |
| `inbox/` | 待分类缓冲区 |
