## ⚠️ 发现的问题

### 问题 1: 以 root 运行
- **等级**: 🟡 中危
- **描述**: OpenClaw 当前以 root 用户运行
- **影响**: 如果被利用，攻击者可能获得系统完全控制权限
- **建议**: 
  1. 创建专用用户 `useradd -r -s /bin/false openclaw`
  2. 迁移数据到该用户目录
  3. 使用 systemd 服务以该用户运行
