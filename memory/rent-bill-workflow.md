# 13B402 租金账单报告机制

## 工作流程

```
每月25日 9:00
    ↓
自动提醒：请发送水电气账单截图
    ↓
你发送截图（水费、电费、燃气费）
    ↓
我读取数据并核对
    ↓
生成双份报告
    ↓
个人查账版 → 飞书私信给你
租户通知版 → 按标准格式生成，你复制发送给租户
```

---

## 报告类型

### 1. 个人查账版（飞书私信）

**包含内容**：
- 完整费用明细（含租金）
- 每项费用的时间周期
- 用量详情（m³、度）
- 收费标准（阶梯计价）
- 未出账单说明
- 历史记录对比

**文件命名**：`reports/rent-bill-YYYY-MM.md`

---

### 2. 租户通知版（微信发送）

**标准格式（版本B）**：

```
🏠 13B402 房租账单通知

📅 租期：YYYY年M月D日 - M月D日

【费用明细】
1. 物业费：¥XXX.XX（周期）
2. 水费：¥XX.XX 💧（周期，Xm³）
3. 电费：¥XX.XX ⚡（周期，X度）
4. 燃气费：¥XX.XX 🔥（周期，Xm³）

💰 本月应付：¥XXX.XX

✅ 下月租金（周期）：已收 ¥X,XXX

📝 待出账单（下月结算）：
• 水费（周期）
• 电费（周期）
• 燃气费（周期）

⏰ 请于M月D日前支付
💳 支付方式：微信/支付宝/银行转账
```

**关键要素**：
- 🏠 房号标识
- 📅 租期明确
- 费用明细（4项）
- 💧⚡🔥  emoji区分水电气
- 💰 应付金额突出
- ✅ 租金状态说明
- 📝 未出账单预告
- ⏰ 支付截止时间

## 未出账单处理

每月账单存在时间差，需明确说明：

| 费用项 | 出账时间 | 结算方式 |
|--------|----------|----------|
| 水费 | 每月1日 | 滞后1个月 |
| 电费 | 每月1日 | 滞后1个月 |
| 燃气费 | 每月18日 | 上月18日-本月18日 |

**说明模板**：
> 本月（X月X日-X月X日）实际产生但尚未出具账单的费用：
> • 水费（X.X-X.X）
> • 电费（X.X-X.X）
> • 燃气费（X.X-X.X）
> 以上费用将于下月账单统一结算。
