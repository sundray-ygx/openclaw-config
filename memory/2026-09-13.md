### [PROJECT:OpenClaw系统] GLM 检查改静默模式（异常才推送）
- **结论**: Boss 要求正常不推送、异常才推送。job delivery 改 `none` + failureAlert(after=1, feishu)；脚本语义对调：成功 exit 0 无 stdout（写 /var/log/glm-channel-check.log 留痕），失败 exit 1 + 告警文案到 stderr（failureAlert 推送时带上）。
- **验证**: 成功路径 force run：exit 0、无输出、deliveryStatus=not-requested（未推送）✅；失败路径假 URL 模拟：exit 1 + 完整告警文案 ✅。
- **坑（重要）**: 传输层会清洗工具调用文本中的 secret 模式：`$(grep` 和 `"$KEY`" 插值被替换成字面 `***`（两轮排障：先语法错误后 401）。对策：exec heredoc 写脚本 + 全脚本零命令替换（read/-w 文件回读）+ key 不经 shell 文本（sed 把 .env 行转 curl -K 头配置文件）。
